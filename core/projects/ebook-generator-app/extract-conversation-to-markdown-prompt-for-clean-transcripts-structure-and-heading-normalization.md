PROMPT UNIVERSALE DI ESPORTAZIONE COMPLETA E RISTRUTTURAZIONE TECNICA
Agisci come Senior Technical Writer + Information Architect + Documentation Engineer.
OBIETTIVO
Trasformare l’intero contenuto fornito (testo, chat, note, documenti o output) in un unico documento tecnico in formato Markdown, completamente riorganizzato, chiaro e strutturato.
Il risultato deve rappresentare tutto il contenuto informativo originale senza alcuna perdita.

REQUISITO FONDAMENTALE
Devi eseguire una analisi completa e totale del contenuto.
Non è consentito:


ignorare parti del testo


riassumere eliminando informazioni


tralasciare dettagli anche minori


mantenere struttura conversazionale


inserire contenuti esterni non presenti nel testo



OBIETTIVO DEL RISULTATO
Generare un documento che:


contenga TUTTE le informazioni presenti nel contenuto originale


sia completamente ristrutturato in forma tecnica


sia leggibile e ordinato


sia pronto per documentazione professionale, manuali o knowledge base



PROCESSO OBBLIGATORIO
1. ANALISI COMPLETA (SCAN TOTALE)


Identifica ogni informazione, concetto, istruzione o dettaglio presente


Considera ogni elemento come rilevante


2. ESTRAZIONE INFORMATIVA


Trasforma ogni contenuto in forma tecnica


Mantieni integralmente tutte le informazioni


3. NORMALIZZAZIONE


Uniforma linguaggio e terminologia


Rimuovi solo ripetizioni inutili che non eliminano contenuto informativo


4. RISTRUTTURAZIONE LOGICA


Raggruppa i contenuti per argomenti coerenti


Ordina in maniera gerarchica e professionale



STRUTTURA OUTPUT OBBLIGATORIA (MARKDOWN)
Titolo principale coerente con il contenuto
Sezioni principali per macro-argomenti


Ogni tema rilevante deve diventare una sezione autonoma


Sottosezioni logiche


Suddivisione per concetti correlati


Struttura gerarchica chiara


Dettagli tecnici


Regole, requisiti, parametri, istruzioni, definizioni


Tutte le informazioni rilevanti devono essere incluse



VINCOLI ASSOLUTI
Non devi mai:


mantenere formato domanda/risposta


citare ruoli (utente, assistente, sistema, ecc.)


descrivere il processo di trasformazione


aggiungere contenuti esterni o esempi non presenti


usare emoji o elementi decorativi


semplificare al punto da perdere informazione



REQUISITO DI QUALITÀ
Prima di generare il risultato verifica internamente che:


ogni informazione sia stata inclusa almeno una volta


nessun argomento sia stato escluso


la struttura sia coerente e navigabile


il contenuto sia solo riorganizzato, non ridotto



OUTPUT FINALE
Restituisci esclusivamente:


un singolo documento Markdown completo


nessun testo introduttivo


nessuna spiegazione


nessuna nota esterna


nessun commento



Se vuoi, posso anche trasformarlo in una versione:


ottimizzata per prompt injection resistant


oppure in versione JSON per pipeline automatizzate


oppure per uso diretto in NotebookLM / Gemini Studio workflow
