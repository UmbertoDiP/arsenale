PROMPT GENERICO PER RIORGANIZZAZIONE CARTELLE Devi riorganizzare completamente una cartella sul mio computer seguendo questo processo: FASE 1 - ANALISI INIZIALE: 1. Scansiona tutti i file e cartelle presenti 2. Analizza la struttura attuale e identifica le categorie logiche 3. Proponi una struttura gerarchica organizzata "a matrioska" (cartelle dentro cartelle) 4. Chiedi conferma prima di procedere FASE 2 - RIORGANIZZAZIONE: 1. Crea la struttura di cartelle principale con nomi chiari e numerati 2. Crea sottocartelle tematiche per ogni categoria 3. Sposta tutti i file nelle posizioni appropriate 4. NON eliminare nulla in questa fase, solo riorganizzare 5. Mostra un riepilogo della nuova struttura FASE 3 - PULIZIA E OTTIMIZZAZIONE: 1. Identifica file potenzialmente eliminabili: - File temporanei (.tmp, .log vecchi, .bak) - File di test e duplicati - Installer e archivi molto grossi già utilizzati - File con nomi come "prova", "test", "cancellami" - Backup vecchi 2. Per ogni file/cartella sospetta, chiedi conferma PRIMA di eliminare 3. Mostra dimensione file e ultima modifica 4. Calcola spazio totale liberabile FASE 4 - SCANSIONE FINALE: 1. Cerca file duplicati per nome o contenuto 2. Identifica file molto grossi (>50MB) e valuta se necessari 3. Trova file non acceduti da molto tempo 4. Proponi ulteriori ottimizzazioni della struttura se necessario REGOLE IMPORTANTI: - Non eliminare MAI nulla senza conferma esplicita - Chiedi conferma uno per uno o per categorie chiare - Dai sempre il percorso completo dei file - Mostra sempre la dimensione dei file - Calcola lo spazio totale liberato - Se trovi file importanti (documenti personali, foto, ecc.) segnalali - Nascondi cartelle di sistema con attributo Hidden se necessario La cartella da riorganizzare è: [INSERISCI PERCORSO]
